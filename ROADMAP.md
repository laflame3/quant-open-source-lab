# Roadmap

## Phase 1: Backtrader / vectorbt Basics

- Run basic installation checks.
- Build minimal moving-average and trend-following demos.
- Compare event-driven and vectorized backtesting workflows.
- Record common pitfalls around data format, commissions, slippage, and plotting.

## Phase 2: Qlib Machine Learning Quant Workflow

- Understand Qlib's data layer, feature pipeline, model training, and evaluation flow.
- Run a minimal ML-based stock selection or ranking demo.
- Connect Qlib concepts with prior XGBoost, LSTM, Transformer, and multi-factor work.

## Phase 3: Lean Industrial Event-Driven Architecture

- Study Lean's algorithm structure, data subscription model, order model, and live trading abstractions.
- Run a minimal algorithm locally if the environment allows.
- Compare Lean with Backtrader from architecture and production-readiness perspectives.

## Phase 4: OpenBB Financial Data Research Terminal

- Understand OpenBB's role as a research terminal and data access layer.
- Test useful data workflows for equities, macro, crypto, and futures-related research.
- Record data-source limitations, authentication needs, and reproducibility concerns.

## Phase 5: Personal CTA / ML / Agent Quant Research Demo

- Build personal demos that connect open-source frameworks with CTA, factors, and ML.
- Keep examples small, reproducible, and easy to explain on GitHub.
- Explore agent-assisted research workflows only after the base quant workflows are clear.
