# Learning Method

My learning process for each open-source quant project follows a fixed sequence.

## 1. Run A Demo First

Start by running the smallest official or self-written demo. The first goal is to confirm the environment, data format, and basic workflow.

## 2. Understand The Architecture

After the demo works, read the README, documentation structure, examples, and core modules to understand how the framework is organized.

## 3. Write A Minimal Reproduction

Create a small demo from scratch, preferably using a familiar strategy such as moving-average crossover, trend following, or a simple factor signal.

## 4. Summarize Applicable Scenarios

Record when the framework is useful, when it is too heavy, and how it fits into CTA, futures, cross-sectional factors, backtesting, or ML research.

## 5. Try Issues, PRs, Or Documentation Contributions

After building enough understanding, look for small contribution points such as documentation fixes, example improvements, issue reproduction, or simple PRs.
