# Project Overview

This repository is a personal learning lab for open-source quantitative research frameworks. It focuses on understanding real tools through documentation reading, runnable demos, architecture notes, and practical research comparisons.

The long-term goal is to build a GitHub-visible record of how I study, test, and evaluate quant research tools, especially in relation to CTA, futures, trend following, factor research, and machine learning.

## Principles

- Keep notes honest and reproducible.
- Prefer minimal working demos over abstract summaries.
- Avoid copying upstream project source code into this repository.
- Track real learning progress with meaningful commits.
- Record limitations, failed attempts, and environment issues.
