# Quant Framework Map

## Backtrader

- Main role: event-driven backtesting.
- Useful for: strategy prototypes, order simulation, data feeds, indicators, analyzers.
- Learning angle: understand classic event-driven backtest engines and CTA-style strategy logic.

## vectorbt

- Main role: vectorized backtesting.
- Useful for: fast parameter sweeps, signal research, factor experiments, portfolio simulations.
- Learning angle: compare vectorized research speed with event-driven realism.

## Qlib

- Main role: AI quant research workflow.
- Useful for: data processing, feature engineering, model training, prediction, portfolio construction, and evaluation.
- Learning angle: connect machine learning models with a structured quant research pipeline.

## Lean

- Main role: professional-grade backtesting and live trading engine.
- Useful for: industrial event-driven architecture, multi-asset algorithms, live trading abstractions.
- Learning angle: understand production-oriented engine design beyond notebook-level research.

## OpenBB

- Main role: financial data terminal and research platform.
- Useful for: data exploration, financial research, market data workflows, and terminal-style analysis.
- Learning angle: evaluate data access and research productivity for personal quant workflows.
